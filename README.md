# Пси-Эксперт

Сайт Первого Псковского профессионального психологического центра. Классический Django без React: каталог услуг, новости, полезные видео, регистрация и четыре роли (гость, клиент, менеджер, администратор).

## Visual Studio 2022

1. Установите рабочую нагрузку «Разработка на Python».
2. Откройте файл `psi-exp.sln`.
3. Если среда попросит интерпретатор, укажите Python 3.10 или новее и создайте виртуальное окружение в папке `PsiExpert`.
4. В консоли этой среды выполните:

```
pip install -r requirements.txt
```

5. База уже заполнена (`db.sqlite3`). Если её нет:

```
python manage.py migrate
python manage.py seed
```

6. Запуск: клавиша F5. Проект помечен как Django launcher, стартовый файл — `manage.py`, модуль настроек — `PsiExpert.settings`. Сайт откроется на http://127.0.0.1:8000/.

Команды выполняются из папки `PsiExpert` (там лежит `manage.py`).

## Учебные входы

- администратор: `admin` / `PsiAdmin!26`
- менеджер: `manager` / `PsiManager!26`
- клиент: `client` / `PsiClient!26`

Панель администратора: `/panel/`. Стандартная админка Django: `/admin/`.
